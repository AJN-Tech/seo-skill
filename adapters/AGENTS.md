## SEO work

When a task involves SEO — audits, crawlability, indexing, hreflang/localization,
metadata, structured data, robots.txt, sitemaps, llms.txt, Core Web Vitals, AI crawler
policy or Search Console — read the `seo` skill before acting:

- Global install: `~/.agents/skills/seo/SKILL.md`
- Claude Code: `~/.claude/skills/seo/SKILL.md`
- Project install: `.agents/skills/seo/SKILL.md`

Then follow its rules: evidence for every finding, never fabricate statistics/testimonials,
separate repo fixes from hosting fixes, and verify the finished work. The bundled
read-only auditor is `scripts/seo-audit.mjs` inside the skill directory.
